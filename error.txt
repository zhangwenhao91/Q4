Description:
  Profile Ascend C operators by running the application on an Ascend device.

Usage:
  msopprof [options] (<application> [application-args] | --config <FILE>)

Optional arguments:
  Exactly one of <application> and --config must be specified.
  -h, --help                                Show help message.
  -V, --version                             Show version information.
      --config <FILE>                       JSON operator configuration file.
      --application <FILE>                  Application executable path.
      --output <DIR>                        Output directory [default: ./].
      --aic-metrics <NAME>[,<NAME>...]      Enable collection ability type:
                                              Supported values: ArithmeticUtilization | MemoryUB | Memory | MemoryL0 | L2Cache |
                                                | PipeUtilization | ResourceConflictRatio | Default | BasicInfo | Roofline |
                                                | Occupancy | TimelineDetail | KernelScale | Source | MemoryDetail |
                                                | PCSampling | PipeTimeline | InstrTimeline |
      --instr-timeline-pipe <PIPE>          Specify the pipe for InstrTimeline.
      --kernel-name <NAME>                  Specify the kernel name to profile.
                                              Not effective in config mode.
      --launch-count <N>                    Kernel launches to collect (1-5000) [default: 1].
      --launch-skip-before-match <N>        Kernel launches to skip (0-1000) [default: 0].
      --replay-mode {application,kernel,range}              Data collection replay mode [default: kernel].
      --kill {true,false}                       Kill the process after launch-count [default: false].
      --mstx {true,false}                       Enable mstx API [default: false].
      --mstx-include <RANGE>                Specify the mstx range to collect.
      --warm-up <N>                         Warm-up runs (0-500) [default: 5].
      --core-id <ID>                        Specify the id of cores to be parsed.
                                              Only effective when --aic-metrics=<TIMELINEDETAIL> and only
                                              effective in simulation products.
      --custom-input <FILE>                 JSON file for custom operator input.

Examples:
  msopprof ./my_operator
  msopprof --config ./op_config.json

Output:
  Results are written to <output-dir>/OPPROF_{timestamp}_{random}.

Troubleshooting:
  Check that exactly one input is provided and option values are valid.
