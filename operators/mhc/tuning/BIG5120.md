# 上游原版big-fuse hidden=5120

```bash
bash operators/mhc/tuning/run_big5120.sh smoke
bash operators/mhc/tuning/run_big5120.sh all
python operators/mhc/matched/collect_results.py --root results/mhc-big5120
```

三侧同输入、同进程，12轮覆盖两次三侧位置/正反顺序周期；每轮100次，预热100次，
三个独立进程，N=64/128/256/512/8192。每侧完整计入计算、输出和工作区分配。

- tilelang_upstream_big_fuse_h5120：未经修改的上游融合尾部公开wrapper＋现有DeepGEMM投影。
- tilelang_upstream_big_fuse_bound_h5120：相同数值kernel，公开compile预绑定。
- ascendc_original_pre_sinkhorn：原版PreV2＋Sinkhorn，无PyTorch数值adaptor。

原版上游源码固定c1cf914并校验哈希。使用本次新pre混合残差，BF16特征、FP32权重，
norm_eps=1e-20、hc_eps=1e-6、20次Sinkhorn，验证三项共同输出及所有两侧互验。
AC仍完整计算next_pre及PreV2缓存，丢弃返回值不消除其计时内工作；
TL只生成三个主输出。因此应标为相同hidden和主计算语义、不同原生输出边界，
不能宣称所有缓存工作完全相同。

测试上游要求的N为16倍数；额外check覆盖16/32/64/112/144/256/528。
输出分配和全部数值计算每次重做，无持久输出，无图重放。
all预期43份正确性文件、15份API摘要、15份profile；每个TL调用2kernel，
AC调用2kernel，每个profile每类kernel30条。
该测试与现有shifted5120旧pre语义不同，结果分目录保存。
