# mHC 测试结果与加速比汇总

汇总日期：2026-10-31。记录截至本报告提交时的设备测试结果，不包含新增设备实验。

以下均为完整 API 的 event 延迟，单位 μs，包含计算与输出/工作区分配。
数值为三个独立进程各自轮次中位数的中位数。
**AC/TL > 1 表示 TileLang 更快**。各表使用对应同轮结果，不跨轮混算加速比。
不同 hidden、pre 语义和输出边界分别列出。

## 1. shifted Pre，hidden=5120

使用传入的旧 pre，输出 layer_input、next_pre_mix、post_mix、comb_mix 四项。
AC 为根据固定上游适配的原生实现，不是未经修改的官方融合算子；双方规格一致。

| N | AC 适配版 | TL 两 kernel | AC/TL | TL 三 kernel | AC/TL |
|---|---:|---:|---:|---:|---:|
| 64 | 27.60 | 26.47 | 1.043× | **25.73** | **1.073×** |
| 128 | 27.90 | 29.20 | 0.955× | **24.72** | **1.129×** |
| 256 | 27.37 | 29.75 | 0.920× | **25.90** | **1.057×** |
| 512 | 40.82 | 30.20 | 1.351× | **28.64** | **1.425×** |
| 8192 | 708.09 | **544.50** | **1.300×** | 586.43 | 1.207× |

五个已测 N 均有 TL 版本超过适配 AC。128/256/512 采用三 kernel 更优，
8192 采用两 kernel 更优；64 的两种 TL 版本优劣有波动。
512～8192 的交叉点尚未测定，不据此设定任意 N 的通用分派阈值。

- 三 kernel：旧 pre apply → 投影/平方和 → RMS、系数映射与 Sinkhorn。
- 两 kernel：投影/平方和 → RMS、系数映射、Sinkhorn 与旧 pre apply 融合尾部。

本轮 1104 项输出检查、92 项原始投影检查通过。
[完整报告](mhc_split/report.md) · [原始汇总](mhc_split/summary.json)

## 2. 原生 Pre 语义，hidden=4096

使用本次新 pre，返回相同三项主输出，与未经修改的原版融合 AC 同规格。
四侧共享同一组输入，在同一进程轮换位置和正反顺序计时。
上游 TL 融合路径均完整包含 DeepGEMM-Ascend 投影。

| N | 原版融合 AC | 上游 TL 普通调用 | AC/TL | 上游 TL 预绑定 | AC/TL | 改造 TL 三 kernel | AC/TL |
|---|---:|---:|---:|---:|---:|---:|---:|
| 64 | 21.14 | 41.10 | 0.514× | **21.90** | **0.965×** | 24.54 | 0.861× |
| 128 | 24.62 | 41.03 | 0.600× | **24.16** | **1.019×** | 24.46 | 1.007× |
| 256 | 21.33 | 41.65 | 0.512× | **24.74** | **0.862×** | 24.79 | 0.861× |
| 512 | 27.56 | 42.21 | 0.653× | **25.57** | **1.078×** | 26.10 | 1.056× |
| 8192 | 617.18 | 487.83 | 1.265× | **487.69** | **1.266×** | 522.00 | 1.182× |

- 上游普通调用：仅 8192 的三个进程均领先 AC。
- 上游预绑定：512、8192 的三个进程均领先 AC；128 两胜一负，不能认定稳定胜出。
- 64/256 的预绑定汇总仍慢于 AC；64 也有进程间胜负波动。
- 大 N 下，上游融合路径优于当前改造的三 kernel。

上游原版指固定 TileKernels `c1cf914a82e6901c679445f872051ce44ac2cc63` 的
`mhc_pre_big_fuse_fwd` wrapper 和 Ascend 数值尾部，源码哈希校验通过；
投影使用已有 Q4 补丁版 DeepGEMM-Ascend，不声称整个组合均未经适配。
预绑定通过公开 compile 接口完成，未修改数值 kernel，没有缓存输出或投影结果。
上游要求 N 为 16 的倍数，非整 tile 的正确性样例明确跳过这两个上游候选。

本轮 1467 项输出检查、96 项原始投影检查通过。

## 3. 原生 Pre 语义，hidden=5120

使用本次新 pre。TL 为上游 `mhc_pre_big_fuse_fwd`＋投影；
AC 为未经修改的 PreV2＋Sinkhorn，三侧同输入、同进程轮换顺序计时。

| N | 原版 AC | 上游 TL 普通调用 | AC/TL | 上游 TL 预绑定 | AC/TL |
|---|---:|---:|---:|---:|---:|
| 64 | 29.61 | 41.04 | 0.721× | **25.82** | **1.147×** |
| 128 | 37.51 | 41.46 | 0.905× | **28.23** | **1.329×** |
| 256 | 30.02 | 41.40 | 0.725× | **28.75** | **1.044×** |
| 512 | 40.24 | 41.46 | 0.971× | **29.17** | **1.380×** |
| 8192 | 706.43 | 536.62 | 1.316× | **536.07** | **1.318×** |

普通调用仅 8192 的三个进程均领先 AC。
预绑定版在 64/128/512/8192 的三个进程均领先；256 两胜一负，尚不稳定。
128 的具体加速比也随 AC 进程波动变化，不表示每次都有 1.329× 收益。

这组不能称为完全相同输出规格：AC 额外生成 next_pre 和 PreV2 缓存，
额外工作完整计时；TL 只生成三项主输出。比较的是同 hidden、同主计算语义下的
完整原生路径。原版融合 AC PreSinkhorn 不支持 5120，因此没有它在 5120 上的实测数据。

本轮 774 项输出检查、86 项原始投影检查通过。

## 5. shifted 5120 的历史优化过程

各阶段使用当轮 AC/TL；跨轮设备状态及 AC 耗时可能变化。

| TL 阶段 | N=128 | N=512 | N=8192 |
|---|---:|---:|---:|
| 原始五 kernel 组合 | 0.346× | 0.514× | 1.098× |
| 普通 JIT 三 kernel | 0.533× | 0.798× | 1.214× |
| 普通 JIT 两 kernel | 0.608× | 0.908× | 1.309× |
| 预绑定两 kernel | 0.972× | 1.346× | 1.297× |
| 最新预绑定三 kernel | **1.129×** | **1.425×** | 1.207× |

“原始五 kernel”是 TileKernels 基础算子＋DeepGEMM 投影的组合基线，
不代表上游 `mhc_pre_big_fuse_fwd` 的性能。五阶段为旧 pre apply、投影/平方和、
reduce/RMS、split mixes、Sinkhorn。

主要收益来自尾部融合、公开 compile 预绑定，以及小 N 将旧 pre apply 独立执行。
新 pre 路径的 apply 有真实数据依赖，不能直接提前到投影和系数计算之前。

历史报告：[基线](mhc_baseline/report.md)、[纯原生适配 AC 对照](mhc_matched/report.md)、
[普通 JIT 融合](mhc_fusion/report.md)、[预绑定两 kernel](mhc_bound/report.md)、
[预绑定两/三 kernel](mhc_split/report.md)。
早期含 PyTorch adaptor 的 AC 组合路径所得 4.823×，不计作对纯原生 AC 的有效结论。

## 结论与适用边界

- shifted5120 同规格对适配 AC：已测五个 N 均有领先候选，最高 1.425×。
- 原生语义4096 同规格对原版融合 AC：上游预绑定在512达到1.078×、8192达到1.266×，三个进程均领先。
- 原生语义5120 对原版 PreV2＋Sinkhorn：预绑定汇总1.044～1.380×，但缓存输出边界不同，256存在胜负波动。
- Post 同规格：约1.05×。

这些加速比都是 API 指标。小 N 的预绑定收益主要来自调用路径改善，
不能等同于设备 kernel 全面领先；例如原生5120的64/128/256，TL设备Duration合计
仍高于AC，而部分API结果领先。设备Duration是独立profile的设备工作量，不能与API
直接相减作为精确主机开销分解。各阶段设备数据见对应报告。

全部结果限定当前合成权重、HF32投影及既有smoke精度门限；
动态N仅对已列样例验证，没有宣称任意N、真实模型权重或模型级精度已验收。
不同hidden之间的快慢只能作跨规格对照，不能严格推导未实现的AC融合5120性能。
