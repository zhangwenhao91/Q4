规格：B=1、H=1、S=4096、D=128，BF16 输入与输出，非因果、无 dropout。
双方直接输出 BF16，无 PyTorch 数值补算；不包含 QKV 和输出投影，不是完整 MHA 层。
设备 Ascend950PR_9579，28 AIC / 56 AIV。

最新同轮设备均值：原始 TL 52.632667、KV2 50.975167、S2 50.921633、AC 39.845967。
S2 相对原始 TL 设备耗时减少 3.251%；AC 仍约快 1.278 倍。
S2 相对 KV2 仅少约 0.054 us（0.105%），尚无稳定收益证明，继续保留 KV2 对照。

有收益的方向：softmax 减少 UB 回写、stages=2、输出归一化与 BF16 转换融合、
K/V 双版本缓冲。S 双版本仅是观测最快候选，alpha 保持三版本。
未采用的方向包括 Q64、手工调度、逐行融合、Q 驻留 L0A、首轮 PV 特判、
P 双版本和 L2 提示；其中 alpha 双版本明显退化。

精度：BF16 基线 36 项通过；最新 S/alpha 分拆实验 90 项通过。
门限 relative L2 <= 1%、max abs <= 0.02，使用 CPU 参考及双方互验。

流水线采集已成功；重建后 S2 53.164001、KV2 52.669998，快慢方向与先前单次诊断不同。
这些值不替代常规基准。原始时间轴尚未传回当前仓库，未定位物理核调度尾部或关键等待。
旧 Q4 删除后已恢复必要依赖并完成新采集；导出必须使用新采集路径。

## mHC 原生 Pre 语义，hidden=5120

AC 是原版 PreV2 + Sinkhorn；TL 是上游融合尾部加兼容投影。
共同三项主输出一致，但 AC 额外生成 next_pre 和缓存，计入全部开销。
因此输出工作范围并非完全相同；原版融合 PreSinkhorn 没有 5120 实测结果。

| N | AC | TL 普通调用 | TL 预绑定 | AC/TL 预绑定 |
|---|---:|---:|---:|---:|
| 64 | 29.61 | 41.04 | 25.82 | 1.147 |
| 128 | 37.51 | 41.46 | 28.23 | 1.329 |
| 256 | 30.02 | 41.40 | 28.75 | 1.044 |
| 512 | 40.24 | 41.46 | 29.17 | 1.380 |
| 8192 | 706.43 | 536.62 | 536.07 | 1.318 |

预绑定 64/128/512/8192 三个进程均领先；256 两胜一负。
小 N 的 API 优势不等于设备 kernel 全面领先：64/128/256 的 TL 设备工作量仍较高。
774 项输出、86 项投影/平方和检查通过。
